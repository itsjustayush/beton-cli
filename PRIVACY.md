# Privacy

BETON is local-first.

The core application stores configuration, notes, and local metadata on the user’s machine. It does not require an account, does not upload notes, and does not transmit clipboard contents. Network access occurs only when a user explicitly invokes a network-oriented command such as web search.

Future integrations that access third-party services must be optional, documented, and separately identifiable. Any analytics or telemetry, if ever introduced, must be opt-in and must not include note text, clipboard contents, file contents, or command arguments by default.
